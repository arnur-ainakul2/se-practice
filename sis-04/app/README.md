# Smart Campus Room Availability Checker

This fictional, read-only app filters campus rooms by capacity and equipment and checks a selected room's availability.

## Requirements

- Node.js and npm

## Install dependencies

```sh
npm install
```

## Run the development server

```sh
npm run dev
```

## Run automated tests

```sh
npx vitest run
```

## Other project checks

```sh
npm run typecheck
npm run build
npm run lint
```
